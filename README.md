
# Lecture 8 — Fixing a Buggy Python Script Using AI

## Project Overview

This project demonstrates testing and debugging a Python student utility program using the RED → FIX → GREEN cycle.

## Files

- `student_utils.py` — Contains functions to calculate averages, check passing marks, and assign grades.
- `test_student_utils.py` — Contains 9 unit tests for the expected behaviour.
- `bug_notes.md` — Documents the identified bugs, their causes, and fixes.

## How to Run the Tests

Run this command in a terminal with Python installed:

```bash
python test_student_utils.py
```

## Testing Process

1. **RED:** Run the tests against the original buggy code.
2. **FIX:** Correct the implementation without changing the tests.
3. **GREEN:** Run the same 9 tests again and verify the results.
